# Canonical M3 report/demo artifacts — v0.2.0-rc2

Description updated November 24, 2026. This update documents the current main
deployment and licensing; the existing tag, model files, hashes and attached
assets are unchanged. rc1 remains available as a historical experiment.

## Current code and demo

- Code: [main branch](https://github.com/its-spark-dev/amazon-review-sentiment-ai/tree/main), entry point `app.py`.
- [Live main app](https://amazon-sentiment-ai.streamlit.app/).
- Model tag: `MODELS_VERSION_TAG=v0.2.0-rc2`.
- Initial selection: `tfidf_lr`, the validation-selected recommendation. Users
  can switch among the five approved models.
- Zero-feature inputs are withheld; displayed probabilities are explicitly
  described as uncalibrated estimates. This vocabulary guard is not language or
  out-of-domain detection.

Follow the [README setup instructions](https://github.com/its-spark-dev/amazon-review-sentiment-ai/blob/main/README.md), then run:

```bash
MODELS_VERSION_TAG=v0.2.0-rc2 python -m streamlit run app.py
```

The release demo needs no dataset. Main was fully rebooted and verified on
November 24: 10 positive/negative predictions matched canonical rc2 labels and
displayed probabilities, 15 zero-feature inputs were withheld, five recoveries
passed, and empty/markup-only checks passed. These are serving checks, not new
held-out performance measurements. Staging's last recorded check is November 23;
the newer serving behavior was verified on main only. Reboot and verify after
serving-module updates; automatic refresh initially retained old inference behavior.

## Frozen results and reproducibility

All five pipelines, comparison results, loss curve and provenance belong to one
deterministic rc2 run. The feature cutoff orders tied training frequencies
lexically. LR settings and the MLP epoch were chosen using inner validation
before evaluating the unchanged outer test split. The MLP uses epoch 13;
the recommendation is balanced TF-IDF LR with C=0.5, selected by validation
Macro-F1, not test accuracy.

The [M3 results](https://github.com/its-spark-dev/amazon-review-sentiment-ai/blob/main/docs/M3_RESULTS.md)
and [model card](https://github.com/its-spark-dev/amazon-review-sentiment-ai/blob/main/docs/MODEL_CARD.md)
record the scores and their limits. The test was already inspected in M2;
this is not a fresh prospective evaluation or a statistical superiority claim.

[PR #21](https://github.com/its-spark-dev/amazon-review-sentiment-ai/pull/21) is
merged. Its [error analysis and reproduction guide](https://github.com/its-spark-dev/amazon-review-sentiment-ai/blob/main/docs/M4_ERROR_ANALYSIS.md)
provides three figures and eight inspected paraphrases, and reproduces the
aggregates from approved models plus the canonical test CSV without a private
evaluation export. No retraining is required. The November 24 validation passed
190 tests, including 14 focused analysis tests and 17 browser tests; all six
main CI jobs passed at `5545a8b`.

`M3_RELEASE.json` records model/input/source hashes, environment versions,
settings, metrics, timing and loss history. The tracked
[release manifest](https://github.com/its-spark-dev/amazon-review-sentiment-ai/blob/main/models/release_manifest.json)
pins the five model files. `comparison.md` and `mlp_loss.png` are from the same
run. Load only trusted, hash-verified joblib artifacts. Dataset files, raw
evaluation exports and split IDs are not attached.
